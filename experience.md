## OpenNebula Systems

**Cloud Systems Developer**
*June 2024 – September 2026 · Madrid, Spain*

I contributed to **OpenNebula**, an open-source cloud and edge computing platform. During this time, I worked across four releases, from version 6.10 to 7.4, contributing to different parts of the platform.

My work involved backend development, cloud provisioning, API design, troubleshooting, and frontend development.

Key contributions:

- **Platform development:** Designed and developed component APIs and data formats, while investigating performance bottlenecks and bugs across cloud systems.
- **OneFlow:** Extended the orchestration component to support a new role for virtual routers.
- **OneForm:** Designed and implemented an automated cloud provisioning tool to deploy OpenNebula clusters across AWS, Scaleway, and bare-metal environments.
- **Sunstone redesign:** Collaborated with the design team to implement reusable React components, translating Figma designs into the platform's new design system.
- **Development and testing:** Developed backend components using Ruby, Sinatra, and Node.js. Wrote automated tests with RSpec and Cypress, and participated in code reviews.

**Technologies:** Ruby, Sinatra, Node.js, React.js, RSpec, Cypress, AWS, Scaleway.
